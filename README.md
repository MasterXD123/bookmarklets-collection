# 🌐 Web Media Utilities

> 🚀 **Colección de Bookmarklets de automatización:** Scripts optimizados en JavaScript puro para extraer, visualizar y gestionar contenido multimedia directamente desde la barra de marcadores de tu navegador.

---

## 📦 Herramientas Disponibles

### 🎵 1. artlist downloader.js
* **Descripción:** Extractor y automatizador de audio optimizado para la plataforma Artlist.io.
* **Características:**
  * 📡 **Monitoreo de red:** Captura buffers de audio (`.mp3`, `.wav`, `.aac`) en tiempo real mediante `PerformanceObserver`.
  * 🤖 **Simulación Humana:** Ejecuta clics automáticos secuenciales para forzar la carga y captura de las pistas.
  * 🔌 **Listo para IDM:** Genera botones premium en la interfaz para descargar en lote o copiar todas las URLs formateadas para *Internet Download Manager*.

---

### 🖼️ 2. BM-SnapMedia.js
* **Descripción:** Visor y capturador universal de imágenes y videos con interfaz de galería premium integrada.
* **Características:**
  * 🔍 **Escaneo Dinámico:** Detecta nuevo contenido multimedia mientras haces scroll usando `MutationObserver`.
  * ⤢ **Accesos Rápidos:** Inyecta un discreto botón flotante sobre cada elemento multimedia para aislarlo al instante.
  * 💻 **Modo Cine:** Despliega un panel oscuro global con efecto *blur* que incluye un reproductor avanzado, controles de pantalla completa y un carrusel navegable de miniaturas.

---

## 🚀 Instalación y Uso

Sigue estos tres sencillos pasos para tener las herramientas listas en segundos:

| Paso | Acción | Detalle |
| :--- | :--- | :--- |
| **1** | **Copiar** | Abre el archivo `.js` de la herramienta que desees y copia todo su código. |
| **2** | **Crear** | Añade una nueva página/marcador en la **Barra de Marcadores** de tu navegador. |
| **3** | **Configurar** | Ponle un nombre descriptivo (ej. `🎵 Get Artlist`) y en el campo **URL**, pega el código. |

> 💡 **Tip de uso:** Una vez configurado, simplemente navega a tu web favorita (o a la lista de Artlist) y haz clic en el marcador para ejecutar la magia.

---

## 🛡️ Características Técnicas

* **Seguridad 100% Local:** No se envían datos a servidores externos; todo el proceso ocurre en tu pestaña activa.
* **Cero Dependencias:** Escritos en JavaScript Vanilla (puro), garantizando compatibilidad nativa en Chrome, Edge, Brave, Firefox y Safari.
* **Optimización de Memoria:** `BM-SnapMedia.js` cuenta con recolector de basura (*garbage collector*) automático para limpiar eventos al cerrar la interfaz.
